매일 같은 글을 여러 곳에 보내는 분께

백 번 보내던 걸 줄이는 네 가지 길

먼저 알아 두실 것 하나 — 단톡방에 글을 넣는 공식 통로는 없습니다. 카카오가 제공하지 않습니다. 그래서 길은 넷뿐이고, 각각 값이 다릅니다.

네 가지 길

위에서 아래로, 쉽고 안전한 순서입니다.

① 손으로, 대신 열 곳씩 오늘 바로

100번 → 10번 · 무료 · 5분

  • ＋카톡에 이미 있는 기능입니다. 「나와의 채팅」에 한 번 쓰고 전달로 열 곳씩 보냅니다.
  • ＋「각각 보내기」를 고르면 단톡방이 안 생기고 1:1 로 따로 갑니다.
  • －그래도 매일 열 번은 손이 갑니다.

② 컴퓨터 엑셀 매크로 자동 중엔 가장 안전

0번 · 무료 · 윈도우만

  • ＋보내는 동안 컴퓨터를 그대로 씁니다. 화면을 건드리지 않습니다.
  • ＋엉뚱한 사람에게 갈 일이 거의 없습니다 — 창 이름이 명단과 정확히 같을 때만 보냅니다.
  • －윈도우 + 엑셀이 있어야 합니다. 맥은 안 됩니다.

③ 폰 매크로 앱 폰 중엔 이게 낫습니다

0번 · 무료 · MacroDroid 등

  • ＋앱을 만들 필요 없이 스토어에서 받아 설정만 하면 됩니다.
  • －보내는 20~30분 동안 폰을 못 씁니다. 화면을 실제로 눌러 가며 보냅니다.
  • －카톡 화면이 바뀌면 멈춥니다. ②보다 잘못 갈 위험도 큽니다.

④ 폰 앱을 새로 만들기 권하지 않습니다

③과 하는 일이 같은데 장벽만 더 있습니다

  • －설치해도 바로 안 됩니다. 안드로이드 13부터 스토어 밖 앱은 카톡을 조작할 권한이 막힙니다.
  • －③과 같은 방식(화면 조작)이라 얻는 것이 없습니다.

고르셨으면, 이걸 Claude에게 주십시오

만드는 건 Claude와 하시면 됩니다. 다만 Claude가 처음부터 다시 알아보면 한참 헤맵니다. 미리 확인해 둔 사실과 함정을 아래에 모았습니다. 그대로 붙여넣으시면 됩니다.

CLAUDE에게 붙여넣을 글

카카오톡으로 매일 같은 글을 100곳쯤에 보내고 있어. 1:1 채팅과 단톡방이 섞여 있어. 자동으로 보내고 싶은데, 먼저 알아본 사실들이 있으니 이걸 전제로 도와줘. [먼저 확인된 사실 — 다시 찾아보지 않아도 돼] · 단톡방·오픈채팅에 글을 넣는 공식 API 는 없어. 카카오가 제공하지 않아. (2026년 기준) · 카카오 "나에게 보내기" API 는 있지만 텍스트가 최대 200자야. 긴 글은 못 보내. · 카카오톡 채널의 "소식 발행"은 무료지만 푸시 알림이 안 가. 직접 들어와야 보여. · 채널 메시지(알림톡·친구톡)는 건당 8~25원이고 사업자 등록이 있어야 열 수 있어. · 손으로 할 때: 메시지를 길게 눌러 "전달"하면 한 번에 최대 10곳까지 고를 수 있어. "각각 보내기"를 고르면 단톡방이 안 만들어지고 1:1 로 따로 가. 폰과 PC 가 똑같아. [그래서 자동화는 화면/창을 조작하는 수밖에 없어] 윈도우 PC 카톡이 가장 안정적이야. 이유는 이래: · 카톡 대화창은 창 제목이 곧 방 이름이야. FindWindow(클래스, 방이름) 은 제목이 정확히 일치하는 창만 돌려줘. → 이름이 비슷한 엉뚱한 사람에게 가는 사고가 구조적으로 막혀. 이게 제일 중요해. · 창 클래스 (버전마다 다를 수 있으니 내 PC 에서 먼저 확인해 줘): 메인 창 EVA_Window_Dblclk / 대화창 #32770 / 입력칸 RichEdit50W (구버전 RichEdit20W) · SendMessage 로 입력칸에 직접 넣으면 마우스·키보드를 안 뺏겨. 보내는 동안 딴 일을 할 수 있어. 화면을 누르는 방식(pyautogui 등)보다 훨씬 안정적이야. [엑셀 VBA 로 만든다면 이 두 개는 미리 알아둬] · #If VBA7 이전 분기에 LongPtr 를 쓰면 컴파일이 안 돼. 엑셀 2010+ 전제로 가. · StrPtr 는 Const 가 아니라 지역 String 변수에 써야 포인터가 안정적이야. [폰으로 한다면] · 안드로이드 13부터 스토어 밖에서 설치한 앱(APK)은 접근성 권한이 막혀. "제한된 설정 허용"을 손으로 풀어야 해. 그래서 직접 앱을 만드는 건 불리해. · MacroDroid 같은 스토어 앱을 쓰면 그 장벽이 없어. · 다만 폰은 화면을 실제로 눌러서 보내니까, 보내는 20~30분 동안 폰을 못 써. 그리고 카톡 앱은 화면이 자주 바뀌어서 업데이트마다 다시 맞춰야 할 수 있어. [꼭 지켜서 만들어 줘] 1. 방을 연 뒤 창 제목(또는 화면의 방 이름)을 다시 읽어서 내 명단과 같을 때만 보내 줘. 다르면 보내지 말고 건너뛰고 기록해 줘. 잘못 가면 되돌릴 수가 없어. 2. 한글은 타이핑 말고 클립보드에 넣었다가 붙여넣기로. 3. 방과 방 사이에 5~15초 무작위로 쉬어 줘. 몰아서 쏘면 카톡이 전송을 막아. 4. 처음엔 3곳만 보내고 멈추는 시험 모드부터. 5. 보낸 시각을 남겨서, 중간에 멈췄다 다시 돌리면 이어서 하게. [그리고 솔직하게 말해 줘] 이건 카카오 약관에 걸리는 일이야. 계정에 전송 제한이 걸릴 위험이 얼마나 되는지, 내 상황에서 할 만한 일인지 네 의견을 말해 줘.

숫자와 상황은 바꿔서 쓰십시오. 폰으로 하실 거면 「윈도우 PC」 부분을 빼시면 됩니다.

무엇을 고르시든 이 셋은 지키십시오

  • 1보내기 직전에 방 이름을 다시 확인하게 하십시오. 이름이 비슷한 사람에게 한 번 가면 되돌릴 수 없습니다. 위 글의 1번 조건이 그것입니다.
  • 2처음에는 세 곳만 보내십시오. 눈으로 확인한 다음 전체를 도십시오. 백 곳을 한 번에 돌렸다가 어긋나면 끝입니다.
  • 3몰아서 쏘지 마십시오. 방 사이에 5~15초씩 쉬게 하십시오. 짧은 사이에 많이 보내면 카톡이 전송을 잠시 막습니다.
그리고 알고 고르셔야 합니다. ②③④는 카카오 약관이 금지하는 자동 발송입니다. 계정에 전송 제한이 걸릴 수 있고, 매일 쓰시는 계정이면 잃는 것이 큽니다. 위험이 부담스러우시면 ①이 답입니다 — 느리지만 아무것도 잃지 않습니다.
