매일 카톡 보내는 일을 줄이는 법

보내는 횟수를 열 번으로 줄이는 방법

카톡에는 한 번에 열 곳까지 보내는 기능이 이미 들어 있습니다. 설치할 것도 돈 드는 것도 없습니다. 열 번도 매일 하면 일이다 싶으시면, 손을 아예 떼는 길도 아래에 적어 뒀습니다.

100 지금 · 하루
→
10 바꾼 뒤
1:1 일흔 명 → 일곱 번
단톡방 서른 곳 → 세 번

원리는 한 줄입니다

받는 사람마다 새로 쓰지 않습니다. 한 번 쓰고, 그것을 열 곳씩 넘깁니다.

「나와의 채팅」에 오늘 보낼 글을 한 번 씁니다.
그 말풍선을 전달로 열 곳씩 보냅니다.

「나와의 채팅」은 나만 보는 방입니다. 여기가 원본이 되고, 나머지는 전부 복사입니다. 매번 다시 쓰거나 복사·붙여넣기 할 일이 없어집니다.

따라 하기

폰과 컴퓨터 모두 됩니다. 열 곳 제한도 똑같습니다.

  1. 1 카톡에서 내 프로필을 누르고 나와의 채팅을 엽니다. 친구 목록 맨 위, 내 이름을 누르면 나옵니다.
  2. 2 오늘 보낼 글을 여기에 써서 보냅니다.
  3. 3 방금 보낸 말풍선을 길게 누릅니다. 메뉴가 뜹니다.
  4. 4 공유를 누릅니다.
  5. 5 받을 사람과 방을 최대 열 곳까지 고릅니다. 열한 번째부터는 선택이 안 됩니다. 세면서 고르지 않아도 됩니다.
  6. 6 각각 보내기인지 확인하고 보냅니다. 이걸 놓치면 고른 사람들이 한 단톡방에 묶여 서로를 보게 됩니다. 가장 조심할 곳입니다.
  7. 7 3번부터 다시 합니다. 백 곳이면 열 번이면 끝납니다.
  1. 1 컴퓨터 카톡에서 내 프로필을 두 번 눌러 나와의 채팅을 엽니다.
  2. 2 오늘 보낼 글을 써서 보냅니다.
  3. 3 방금 보낸 말풍선에 마우스 오른쪽 버튼을 누릅니다.
  4. 4 전달을 누릅니다.
  5. 5 받을 곳을 최대 열 곳까지 고르고 보냅니다. 1:1로 보내려면 목록에서 친구를, 단톡방에 보내려면 채팅방을 고릅니다.
  6. 6 3번부터 다시 합니다. 컴퓨터가 폰보다 빠릅니다. 글이 길다면 컴퓨터를 권합니다.

알아 두실 것

  • · 친구로 등록된 사람만 고를 수 있습니다. 전화번호만 아는 사람에게는 이 방법으로 못 보냅니다.
  • · 단톡방도 같은 열 곳 제한입니다. 사람과 단톡방을 섞어서 열 곳을 채워도 됩니다.
  • · 보내는 순서를 정해 두십시오. 매일 같은 순서로 고르면 누구를 보냈는지 헷갈리지 않습니다. 자주 보내는 분들을 즐겨찾기에 올려 두면 목록 맨 위에 모여 고르기가 훨씬 빠릅니다.
  • · 같은 글을 아주 짧은 사이에 몰아서 보내면 카톡이 잠시 전송을 막을 수 있습니다. 열 곳씩 나눠 보내는 사이에 조금씩 쉬어 가십시오.

열 번도 매일 하면 일입니다

여기부터는 손을 아예 떼는 길입니다. 대신 값을 치릅니다.

먼저 아셔야 할 것

카톡 창을 대신 눌러 주는 자동화는 카카오 약관에서 금지하고 있습니다. 걸리면 계정에 전송 제한이 걸릴 수 있고, 매일 쓰시는 계정이면 잃는 것이 큽니다.

위험을 실제로 낮추는 건 사람처럼 천천히 보내는 것뿐입니다. 아래 지시문에 그 조건들을 미리 넣어 뒀습니다. 그래도 0은 아닙니다 — 알고 고르셔야 합니다.

길은 엑셀입니다. 엑셀은 이미 쓰고 계실 테니 새로 설치할 것이 없고, 명단을 시트에 적어 두면 되니 관리도 쉽습니다. 무엇보다 보내는 동안 키보드와 마우스를 뺏기지 않습니다 — 카톡 창을 마우스로 누르는 방식이 아니라, 윈도우가 제공하는 통로로 글을 직접 넣기 때문입니다.

먼저 — 이미 만들어진 것이 있습니다

직접 만들기 전에 이것부터 써 보십시오. 무료이고, 카톡이 바뀔 때마다 계속 손봐 온 서식입니다. 이게 맞으면 아무것도 만들 필요가 없습니다.

엑셀 카카오톡 문자보내기 자동화 서식 오빠두엑셀 — 명단을 시트에 적고 버튼을 누르면 순서대로 보냅니다. 내려받으려면 회원가입(무료)이 필요합니다. 버전 4.2.0 (2025-12-29) 받은 사람 27,390명 평점 4.96/5

⚠️ 윈도우 전용입니다(엑셀 2013 이상). 맥에서는 안 됩니다. 그리고 카톡이 크게 바뀌면 한동안 멈출 수 있습니다 — 2024년 업데이트 때 실제로 그랬고, 만든 쪽에서 고쳐 다시 냈습니다.

아니면 — 아래 코드를 그대로 쓰십시오

기성 서식이 안 맞거나 안에서 무슨 일이 일어나는지 보고 싶으시면, 만들어 둔 것을 쓰십시오. 코드를 읽으실 필요는 없습니다. 아래 순서대로만 하시면 됩니다. 10분이면 됩니다.

  1. 엑셀을 새로 켜고 다른 이름으로 저장을 누릅니다. 파일 형식을 「Excel 매크로 사용 통합 문서 (*.xlsm)」로 고르십시오. 보통 xlsx로 저장하면 매크로가 통째로 사라집니다.
  2. Alt + F11 을 누릅니다. 까만 창이 뜹니다. 이게 매크로 편집기입니다. 놀라지 않으셔도 됩니다.
  3. 위쪽 메뉴에서 삽입 → 모듈을 누릅니다. 오른쪽에 빈 흰 칸이 생깁니다.
  4. 아래 「코드 복사」 버튼을 누르고, 그 빈 칸에 Ctrl + V 로 붙여넣습니다. 빈 칸 안을 한 번 누른 다음 붙여넣으셔야 합니다.
  5. Ctrl + S 로 저장하고, 편집기를 닫습니다.
  6. 엑셀 화면에서 Alt + F8 을 누르고 준비_시트만들기를 골라 실행합니다. 「명단」·「내용」·「설정」 시트가 저절로 만들어집니다.
  7. 「명단」 시트 A2부터 받을 곳 이름을 한 줄에 하나씩 적습니다. ⚠️ 카톡에 보이는 이름 그대로 적어야 찾습니다. 띄어쓰기·이모지까지 같아야 합니다.
  8. 「내용」 시트 A1에 보낼 글을 적습니다. 줄을 바꾸실 때는 Alt + Enter 를 쓰십시오.
  9. 카톡을 켜 두고 Alt + F8 → 진단_카톡창을 실행합니다. 내 컴퓨터에서 카톡 창을 찾을 수 있는지 먼저 보는 것입니다. 「진단」 시트에 결과가 적힙니다. 여기서 막히면 다음으로 넘어가지 마십시오.
  10. Alt + F8 → 발송을 실행합니다. 처음에는 시험모드라 3곳에만 갑니다. 카톡에서 눈으로 확인하신 다음, 「설정」 시트 B1을 FALSE로 바꾸시면 전체가 나갑니다.
엑셀 매크로 코드 (378줄)

이 코드가 하는 일은 셋입니다. · 준비_시트만들기 — 시트 세 개를 만들어 줍니다 (처음 한 번만) · 진단_카톡창 — 내 컴퓨터에서 카톡 창을 찾을 수 있는지 확인합니다 · 발송 — 명단을 따라가며 하나씩 보냅니다 안전을 위해 이렇게 만들었습니다. · 방을 연 뒤 창 제목을 다시 읽어, 명단과 정확히 같을 때만 보냅니다. 다르면 보내지 않고 「제목 불일치」라고 적어 둡니다. · 방과 방 사이에 5~15초 무작위로 쉽니다. · 보낸 시각을 B열에 적어 두고, 다시 돌리면 이미 보낸 곳은 건너뜁니다. · 돌아가는 중에 Esc 를 누르면 멈춥니다. · 마우스·키보드를 쓰지 않고 보내므로, 보내는 동안 다른 일을 하셔도 됩니다. 「코드 복사」를 누르면 전체(378줄)가 복사됩니다.

'==========================================================================
'  카카오톡 순차 발송  (엑셀 VBA · 윈도우 전용)
'--------------------------------------------------------------------------
'  왜 이 방식인가
'    마우스로 화면을 누르는 자동화가 아니라, 윈도우가 제공하는 통로
'    (FindWindow / SendMessage)로 카톡 입력칸에 글을 직접 넣는다.
'    → 보내는 동안 키보드·마우스를 뺏기지 않는다. 다른 일을 해도 된다.
'
'  왜 안전한가 (가장 중요)
'    카톡 대화창은 **창 제목이 곧 방 이름**이다.
'    FindWindow(클래스, 방이름) 은 **제목이 정확히 일치하는 창만** 돌려준다.
'    그래서 「이름이 비슷한 엉뚱한 사람에게 가는 일」이 구조적으로 막힌다.
'    보내기 직전에 제목을 **한 번 더** 읽어 대조한다(GetWindowTextW).
'
'  ⚠️ 쓰기 전에
'    · 카카오 약관은 자동 발송을 금지한다. 계정에 전송 제한이 걸릴 수 있다.
'    · 반드시 시트의 [시험모드] = TRUE 로 **3곳만** 먼저 보내고 눈으로 확인할 것.
'    · 카톡이 크게 바뀌면 클래스 이름이 달라질 수 있다 → 먼저 `진단_카톡창` 을 돌린다.
'
'  시트 구성
'    「명단」 시트 : A열=받을 곳 이름(카톡에 보이는 그대로) · B열=보낸 시각 · C열=결과
'    「내용」 시트 : A1 셀에 보낼 글 (여러 줄 가능)
'    「설정」 시트 : B1=시험모드(TRUE/FALSE) · B2=최소쉼(초) · B3=최대쉼(초)

' 카톡 창 클래스 — 버전에 따라 다를 수 있다. 다르면 `진단_카톡창` 결과로 여기를 고친다.
Private Const CLS_MAIN As String = "EVA_Window_Dblclk"   ' 카톡 메인 창
Private Const CLS_CHAT As String = "#32770"              ' 대화창(제목 = 방 이름)
Private Const CLS_EDIT As String = "RichEdit50W"         ' 글 넣는 칸 (구버전: RichEdit20W)

'==========================================================================
'  ① 진단 — 먼저 이것부터 돌린다
'     내 컴퓨터의 카톡 창 구조를 「진단」 시트에 적는다.
'     위의 CLS_* 상수가 맞는지 눈으로 확인하기 위한 것이다.
'==========================================================================
Public Sub 진단_카톡창()
    Dim ws As Worksheet, r As Long
    Set ws = 시트확보("진단")
    ws.Cells.Clear
    ws.Range("A1:D1").Value = Array("종류", "클래스", "제목", "핸들")
    ws.Range("A1:D1").Font.Bold = True
    r = 2

    Dim hMain As LongPtr, sMain As String
    sMain = CLS_MAIN                      ' ⚠️ StrPtr 는 Const 가 아니라 변수에 써야 안전하다
    hMain = FindWindowW(StrPtr(sMain), 0)
    If hMain = 0 Then
        ws.Cells(r, 1).Value = "메인 창을 못 찾음"
        ws.Cells(r, 2).Value = "카톡이 켜져 있는지, 클래스(" & CLS_MAIN & ")가 맞는지 확인"
        ws.Columns.AutoFit
        MsgBox "카톡 메인 창을 못 찾았습니다." & vbCrLf & _
               "카톡을 켜고 다시 돌려 주세요.", vbExclamation
        Exit Sub
    End If
    ws.Cells(r, 1).Value = "메인 창"
    ws.Cells(r, 2).Value = 창클래스(hMain)
    ws.Cells(r, 3).Value = 창제목(hMain)
    ws.Cells(r, 4).Value = CStr(hMain)
    r = r + 1

    ' 지금 열려 있는 대화창을 모두 훑는다 (제목 = 방 이름)
    Dim h As LongPtr, sChat As String
    sChat = CLS_CHAT
    h = FindWindowW(StrPtr(sChat), 0)
    Do While h <> 0
        If IsWindowVisible(h) <> 0 And Len(창제목(h)) > 0 Then
            ws.Cells(r, 1).Value = "대화창(열려 있음)"
            ws.Cells(r, 2).Value = 창클래스(h)
            ws.Cells(r, 3).Value = 창제목(h)
            ws.Cells(r, 4).Value = CStr(h)
            r = r + 1
            ' 그 안의 입력칸도 찾아본다
            Dim hE As LongPtr
            hE = 입력칸찾기(h)
            ws.Cells(r, 1).Value = "  └ 입력칸"
            ws.Cells(r, 2).Value = IIf(hE = 0, "못 찾음 — CLS_EDIT 를 고쳐야 한다", 창클래스(hE))
            ws.Cells(r, 4).Value = IIf(hE = 0, "", CStr(hE))
            r = r + 1
        End If
        h = GetWindow(h, GW_HWNDNEXT)
    Loop

    ws.Columns.AutoFit
    MsgBox "진단을 「진단」 시트에 적었습니다." & vbCrLf & vbCrLf & _
           "· 대화창이 하나도 안 보이면, 카톡에서 아무 방이나 열고 다시 돌려 주세요." & vbCrLf & _
           "· 입력칸이 「못 찾음」이면 코드 위쪽 CLS_EDIT 를 바꿔야 합니다." & vbCrLf & _
           "  (RichEdit50W ↔ RichEdit20W)", vbInformation
End Sub

Public Sub 발송()
    Dim wsL As Worksheet, wsC As Worksheet, wsS As Worksheet
    Set wsL = 시트확보("명단")
    Set wsC = 시트확보("내용")
    Set wsS = 시트확보("설정")

    Dim msg As String
    msg = CStr(wsC.Range("A1").Value)
    If Len(Trim$(msg)) = 0 Then
        MsgBox "「내용」 시트 A1 에 보낼 글이 없습니다.", vbExclamation: Exit Sub
    End If

    Dim 시험 As Boolean, 최소 As Long, 최대 As Long
    시험 = (UCase$(CStr(wsS.Range("B1").Value)) <> "FALSE")   ' 비어 있으면 시험모드
    최소 = 숫자또는(wsS.Range("B2").Value, 5)
    최대 = 숫자또는(wsS.Range("B3").Value, 15)
    If 최대 < 최소 Then 최대 = 최소

    Dim 마지막 As Long
    마지막 = wsL.Cells(wsL.Rows.Count, 1).End(xlUp).Row

CLAUDE에게 붙여넣을 글

카카오톡으로 매일 같은 글을 100곳에 보내고 있어. 1:1 채팅 70명, 단톡방 30곳이야. 손으로 하면 30분씩 걸려서 자동화하고 싶어. 윈도우 PC 에 엑셀과 카톡이 깔려 있어. 엑셀 VBA 로 만들어 줘. 파이썬 같은 걸 새로 설치하고 싶지는 않아. 방식은 이렇게 해 줘: - 마우스로 화면을 누르는 방식 말고, 윈도우 API(FindWindow / FindWindowEx / SendMessage / PostMessage)로 카톡 창에 직접 넣는 방식으로. 그래야 보내는 동안 내가 다른 일을 할 수 있어. - 카톡 창 클래스 이름은 이렇다고 들었어. 버전마다 다를 수 있으니 내 컴퓨터에서 먼저 확인해 줘: 메인 창 EVA_Window_Dblclk / 자식 창 EVA_ChildWindow, EVA_Window 글 넣는 칸 RichEdit50W 또는 RichEdit20W 시트는 이렇게: - A열에 받을 곳 이름(카톡에 보이는 그대로), B열에 보낸 시각 - 보낼 글은 따로 시트 하나에 꼭 지켜야 할 것 (중요한 순서대로): 1. 방을 연 다음 창 제목(방 이름)을 다시 읽어서 A열과 같을 때만 보내 줘. 다르면 보내지 말고 건너뛰고 B열에 이유를 적어 줘. → 이름이 비슷한 사람이 있으면 엉뚱한 사람에게 갈 수 있는데, 그게 제일 무서워. 한 번 가면 되돌릴 수가 없어. 2. 한글은 클립보드에 넣었다가 붙여넣는 방식으로 해 줘. 3. 방과 방 사이에 5초에서 15초 사이로 무작위로 쉬어 줘. 한꺼번에 빠르게 쏘면 카톡이 전송을 잠시 막아. 4. 처음 실행할 때는 3곳에만 보내고 멈추는 시험 모드를 만들어 줘. 내가 눈으로 확인한 다음에 전체를 돌리고 싶어. 5. B열에 보낸 시각이 적힌 곳은 다시 돌려도 건너뛰게 해 줘. 중간에 멈췄다가 이어서 할 수 있게. 6. 돌아가는 중에 Esc 로 멈출 수 있게 해 줘. 먼저 내 컴퓨터에서 카톡 창을 찾을 수 있는지부터 확인해 주고, 안 되면 뭘 어떻게 해야 하는지 알려 줘. 그리고 이게 카카오 약관에 걸리는지, 계정이 막힐 위험이 얼마나 되는지도 솔직하게 말해 줘.

  • · 숫자는 바꿔서 쓰십시오. 100곳·70명·30곳은 예시입니다. 실제 숫자를 적으시면 됩니다.
  • · 맥에서는 안 됩니다. 맥 카톡은 창 이름을 읽을 수 없어서 「엉뚱한 방에 보내지 않기」를 지킬 방법이 없습니다. 그게 지시문의 1번 조건입니다. 윈도우로 하십시오.
